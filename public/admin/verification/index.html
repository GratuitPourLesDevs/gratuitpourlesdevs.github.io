Vérification des offres

Le contrôle visite le site officiel et la source tarifaire de chaque offre publiée. Il est aussi exécuté automatiquement le premier jour de chaque mois.

Lancer un contrôle complet

GitHub vous demandera de confirmer l’exécution du workflow « Vérifier les offres ». Le rapport détaillé sera disponible dans l’exécution.

Ouvrir la vérification dans GitHub ↗
